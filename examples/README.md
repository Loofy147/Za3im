# Example files: evidence labels

- execution-request.example.json is a synthetic request for the current local business-presence vertical slice. It uses fictional business data and does not claim a live OpenAI request was made.
- execution-result.example.json is a synthetic result for schema/consumer tests. It is not a real execution specimen, invoice, or production evidence.
- engine-registry.yaml is a reference registry and is not loaded by the runtime. Candidate agent engines remain disabled.
- experience-manifest.yaml is a design example and is not loaded, installed, or executed by the runtime. Experience export/import is not implemented.

A source file or example becomes implementation evidence only when a runnable path and tests demonstrate the stated behavior.
